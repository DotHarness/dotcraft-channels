# DotCraft Channels

Official messaging plugins for DotCraft. Install published channels from **Plugins → Channels** in DotCraft Desktop.

## Develop

See the [channel plugin guide](https://www.dotcraft.net/extend/channel-modules) and [adapter guide](https://www.dotcraft.net/extend/sdks/channels). To build and test locally, use Node.js 22 or later:

```sh
npm ci
npm test
npm run package
```

Install a plugin from `out/plugins/` to try it in DotCraft.

## Contribute

Open a pull request here to improve an official channel. To submit your own plugin, follow the [official marketplace contribution guide](https://github.com/DotHarness/dotcraft-plugins/blob/main/CONTRIBUTING.md).
